
# ProntoLar Serviços

Site institucional fictício para uma empresa de manutenção residencial.

## Sobre o projeto

O ProntoLar Serviços é um projeto desenvolvido com o objetivo de criar uma presença digital para uma empresa fictícia de manutenção residencial, apresentando seus serviços, informações institucionais e canais de contato.

O projeto faz parte do meu portfólio de desenvolvimento web e tem como foco a aplicação prática dos fundamentos de HTML e CSS.

## Tecnologias utilizadas

- HTML5
- CSS3
